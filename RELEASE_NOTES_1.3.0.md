# VoxLocal 1.3.0

- В настройках оставлены три понятных варианта Whisper: Base, Small и Large v3 Turbo.
- Base используется по умолчанию для быстрой диктовки с микрофона.
- Для аудио- и видеофайлов по умолчанию выбирается Large v3 Turbo, если модель установлена.
- Если Large v3 Turbo ещё не установлена, её можно скачать прямо из окна транскрибации после подтверждения размера.
- Старые скачанные модели не удаляются с компьютера.
