# VoxLocal 1.4.0

- Для транскрибации аудио- и видеофайлов добавлена новая рекомендуемая модель NVIDIA Parakeet TDT 0.6B v3.
- Parakeet точнее распознаёт русскую речь, автоматически расставляет пунктуацию и загружается только после явного подтверждения пользователя.
- Во время загрузки Parakeet показываются полоса прогресса и точный процент; модель занимает около 714 МБ.
- Whisper Base остаётся моделью по умолчанию для быстрой диктовки с микрофона, а установленные Whisper-модели доступны как запасные варианты для файлов.
- Движок whisper.cpp обновлён с 1.9.1 до 1.9.5.
- Добавлен локальный Metal-движок NVIDIA NeMo-Speech.cpp 0.2.0 для Apple Silicon; звук и расшифровка по-прежнему не покидают Mac.
