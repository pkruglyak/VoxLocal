# VoxLocal 1.4.1

- В настройки добавлена отдельная вкладка «Доступы» с живыми статусами микрофона, «Универсального доступа», движка распознавания и выбранной модели.
- Для отсутствующих разрешений добавлены понятные кнопки перехода в нужный раздел Настроек системы и инструкция по удалению устаревшей записи VoxLocal после обновления приложения.
- Экран автоматически перепроверяет разрешения и показывает общий статус готовности VoxLocal.
- При загрузке модели теперь видны точный процент и объём загруженных данных.
- Пока скачивается одна модель, приложение объясняет, почему кнопки загрузки остальных моделей временно недоступны.
